# 깨진 얼굴 연결 수정

## 교체 이유

사용자가 v10의 비뚤어진 얼굴을 지적했다. 잘라 줄인 리트리버의 코·입 조각을 새 머리에 붙였던 방법에서 입가의 불규칙한 경계와 부자연스러운 연결이 남았다. 이를 개선됐다고 전달한 검토 판단도 부적절했다. v10은 거절된 실험으로 보관한다.

## 이번 수정

- 리트리버의 얼굴 메시와 텍스처를 사용하지 않고 머리·볼·주둥이·입 안쪽을 하나의 연속된 표면으로 새로 구성했다.
- 좌우 대칭인 코와 콧구멍, 매끄러운 혀를 새로 만들었다.
- 입술 중앙의 곡선과 콧밑 중심선을 대칭으로 구성했다.
- 눈은 머리의 매끄러운 눈구멍 안에 배치했다.
- 털을 끈 정면·사선부터 확인한 뒤 얼굴 털을 좌우 짝으로 배치했다.

새 머리와 코에서 열린 모서리와 비정상적으로 연결된 모서리는 각각 0개다. 좌우 대칭의 최대 수치 오차는 머리 약 `4.5e-8`, 코 약 `7.5e-9` 장면 단위다. 검사값은 `ArtSource/CleanFace/surface_audit.json`에 기록했다. 이 검사는 표면 연결과 대칭에 관한 것이며 오공이의 닮은 정도를 검증하는 점수는 아니다.

## 파일과 재생성

작업 폴더는 `ArtSource/CleanFace/`다. 사진을 포함한 Blender 파일은 Git에서 제외한다.

- `ogong_clean03_structure.blend`: 털 없는 새 얼굴 구조
- `ogong_clean03.blend`: 털을 포함한 편집 장면
- `clean03_structure_front.png`, `clean03_structure_threequarter.png`: 구조 확인 렌더
- `clean03_front.png`, `clean03_threequarter.png`: 털을 포함한 정면·사선

`sculpt_clean_face.py`는 NumPy와 scikit-image로 연속 표면 데이터를 생성한다. `build_clean_face.py`는 Blender 5.2.2에서 장면을 만들고, `groom_clean_face.py`는 새 표면에 털을 배치한다. 생성 명령은 같은 이름 파일을 덮어쓰므로 직접 편집한 파일은 새 이름으로 저장한다.

저장한 `clean03`을 Blender 5.2.2에서 다시 열어 이전 얼굴 조각이 없는 것, 사진 2장이 내장된 것, 244,916개의 털 곡선 좌표가 유효한 것을 확인했다. 얼굴 속털과 겉털의 좌우 짝 좌표 오차는 0이다. 결과는 `clean03_validation.json`에 저장했다.

## 시각 검토

정면에서 기존 코·입 조각의 불규칙한 테두리와 주둥이의 울퉁불퉁한 연결은 없어졌다. 새 입술과 혀는 중심선 기준으로 정렬돼 있다. 다만 큰 눈의 반사, 단순한 코·입 형상과 고른 털 때문에 인형 같은 인상이 강하다. 구조 교정과 실제 강아지의 사실적인 재현은 별개로 평가한다. 실사 품질을 충족했다고 보고하지 않는다.

이번 범위는 비뚤어진 얼굴과 깨진 연결의 교정이다. 사용자가 제시한 다각도 참고 이미지의 사실적인 완성도에 도달했다고 판정하지 않는다. 전신 연결, 표정·사족 리깅과 앱용 경량화는 후속 작업이다.
