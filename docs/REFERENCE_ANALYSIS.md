## 닮은 정도에 중요한 특징

1. **머리:** 풍성한 흰 털이 둥근 외곽을 만든다. 정면에서는 귀가 털에 일부 묻혀 윤곽이 약하지만 왼쪽 측면에서는 작은 삼각형 귀와 안쪽의 분홍빛이 보인다.
2. **얼굴:** 둥글고 어두운 눈, 작은 검은 코, 짧은 주둥이가 얼굴 중앙에 모인다. 열린 입과 분홍색 혀가 표정의 인상을 크게 좌우한다.
3. **목·가슴:** 얼굴 아래부터 가슴까지 털이 길고 크게 부풀어 다리 윗부분을 가린다.
4. **몸통·다리:** 서 있는 사진에서 몸통은 풍성한 털로 넓게 보이고, 다리는 상대적으로 짧고 발은 작게 보인다. 실제 뼈대 비율은 털 아래에서 확인이 어렵다.
5. **꼬리:** 등 위쪽으로 말려 올라간 풍성한 꼬리가 측면 실루엣의 핵심이다.
6. **털 색:** 전체적으로 흰색으로 보이나 실내 조명이 따뜻하거나 어두워 사진마다 톤이 달라진다. 야외 사진을 우선 참고하고, 재질의 최종 흰색은 중립 조명 사진으로 확인한다.

## 모델링 검토 순서

먼저 털을 제외한 머리·몸통·다리의 기본 체형을 만든다. 다음으로 머리와 가슴의 큰 털 덩어리, 등선과 말린 꼬리를 추가한다. 눈·코·주둥이의 간격을 정면 사진과 비교한 뒤, 입을 다물었을 때와 웃으며 혀를 내밀었을 때의 두 표정을 준비한다. 세부 털과 질감은 큰 실루엣을 승인한 뒤 다듬는다.

## 추가 사진이 있으면 해결되는 부분

- 자연스럽게 서 있는 **정확한 오른쪽 측면**: 좌우 비대칭, 등선, 다리 길이, 주둥이 돌출 정도
- **뒤쪽과 위쪽**: 꼬리 시작점, 엉덩이·등 털의 볼륨
- 밝은 자연광의 **귀·얼굴 근접 사진**: 귀 형태와 실제 털 색
- 입을 다문 정면 사진: 기본 `Idle` 표정

현재 제공된 17장으로 첫 형태와 표정, 앉기·잠자기 자세를 잡을 수 있다. 보이지 않는 오른쪽 측면과 꼬리 밑면은 추후 사진이 있으면 더 정확히 다듬는다.
