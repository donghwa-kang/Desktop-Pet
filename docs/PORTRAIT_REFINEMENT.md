# 오공이 얼굴 다듬기 — portrait02

## 목표와 변경점

clean03의 정돈된 표면을 유지하면서 인형처럼 보이던 눈·코·입과 균일한 털을 다듬었다. 실제 사진 `_06.jpg`와 `_01.png`를 정면 비교에 사용했다. 사진의 렌즈·자세·털 상태가 달라 정확한 3D 치수로 간주하지 않는다.

- 눈을 조금 작게 하고 안으로 넣었다. 위·아래 눈꺼풀을 연속 표면에 구성하고, 눈썹 볼륨을 부드럽게 연결했다.
- 코를 세로로 늘리고 콧구멍과 하단 형태를 수정했다. 코 표면의 미세 요철과 색 변화, 눈의 방사형 홍채 무늬, 혀의 색 변화와 요철을 추가했다.
- 주둥이 양옆을 앞으로 내고 입 중앙의 열린 선을 올렸다. 머리·주둥이·입 안쪽은 같은 표면이다.
- 주둥이의 짧은 털, 얼굴·가슴의 속털과 겉털, 귀의 털, 수염을 별도 Hair Curves로 구성했다. 다발별 흐름과 휘어짐, 뿌리와 끝의 색 차이를 적용했다.
- 얼굴의 기본 표면은 대칭이다. 털 끝에는 작은 차이를 주었다.

## 편집 파일

`ArtSource/PortraitStudy/ogong_portrait02.blend`

Blender 5.2.2 LTS에서 생성·재개방 검사했다. 사진 2장은 파일 안에 내장돼 있다. 타임라인 1프레임은 정면, 2프레임은 45도, 3프레임은 측면 카메라다. 카메라 화면은 숫자패드 0으로 전환할 수 있다. 털은 `Balanced_Facial_Coat` 컬렉션에서 숨기거나 편집할 수 있다.

작업 범위는 **얼굴과 가슴**이다. 285,028개 털 곡선과 조밀한 삼각형 표면을 사용하는 렌더 연구용 모델이다. 전신, 변형용 토폴로지, 리깅, 애니메이션, Unity용 털 변환은 포함하지 않는다. 오공이와의 최종 유사도나 실사 품질을 충족했다고 판정하지 않는다.

## 시각 검토와 남은 차이

정면과 45도 렌더에서 코·입의 연결이 끊기지 않고, 주둥이의 짧은 털과 가슴의 긴 털이 구분된다. 다만 눈의 큰 반사와 단순한 안구 재질, 매끈한 혀, 지나치게 고른 얼굴 털 때문에 인형 같은 인상이 남는다. 실제 사진의 눈꺼풀 가장자리와 각막·홍채의 깊이, 혀 표면의 세밀한 질감, 덜 균일한 털 다발은 추가 개선 대상이다. 이번 결과를 실사 기준 통과로 기록하지 않는다.

측면에서는 턱 아래 털이 길게 떨어지는 모양과 정수리 털이 서 있는 모양이 두드러진다. 사진에 맞춘 턱·정수리의 국소적인 털 손질과 혀의 단면·말림도 후속 수정 대상으로 남긴다. 정면은 840×882, 45도·측면은 720×756의 실제 Cycles 렌더로 저장했다.

## 재현과 확인

1. `sculpt_portrait.py`: NumPy·SciPy·scikit-image로 머리와 코 생성. 형태 정의는 `portrait_fields.py`.
2. `build_portrait.py`: Blender 5.2.2 Python API로 눈·혀·재질·구조 장면 생성.
3. `groom_portrait.py`: 부위별 털과 검토 카메라 생성·저장·렌더.
4. `render_portrait.py`: 저장된 파일에서 선택한 카메라만 렌더.
5. `audit_portrait.py`: 저장 파일을 다시 열어 표면, 털 좌표·반경·표면 연결, 내장 사진·카메라 확인.

같은 태그로 실행하면 해당 파일을 덮어쓰므로 직접 수정한 파일은 다른 이름으로 저장한다. 생성물과 개인 사진은 Git에서 제외한다.

재개방 검사에서 머리와 코의 열린 모서리 및 비다양체 모서리는 각각 0개였다. 모든 털의 좌표·반경과 표면 연결이 유효했다. 수치 검사 결과는 `portrait02_validation.json`에 저장했다. 구조 검사 결과는 시각적 유사도의 점수가 아니다.
