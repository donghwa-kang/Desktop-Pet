# 포메라니안 얼굴 수정

**v10은 사용자가 얼굴이 비뚤고 입가가 불규칙하다고 지적해 거절한 버전이다.** 아래는 이전 제작 기록이며, 이 표면을 최종 제작 기반으로 사용하지 않는다. 새 코·입·머리 표면으로 교체한 작업은 [깨진 얼굴 연결 수정](CLEAN_FACE.md)을 따른다.

## 범위

사용자의 요청에 따라 리트리버의 얼굴과 귀를 그대로 두었던 털 시험을 수정했다. 현재 결과는 얼굴과 가슴의 편집용 3D 초상이다. 전신 모델, 표정 리깅, 앱용 자산의 완성본은 아니다.

기준 사진은 정면 얼굴이 선명한 `KakaoTalk_20261005_184824793_06.jpg`와 `_01.png`다. 두 사진을 Blender 파일에 내장했다. 사진에서 보이지 않는 두개골의 깊이와 귀 밑부분은 추정해서 만들었다.

## 실제 변경

- 기존 리트리버 머리·가슴·늘어진 귀 표면을 제거하고, 둥근 머리와 목·가슴을 잇는 사각 면 표면을 새로 구성했다.
- 기존 코·입·혀의 세부 형상과 UV는 일부 활용하되, 주둥이 깊이와 눈 아래 얼굴 길이를 줄였다. 코의 높이는 별도로 보정하고 주변 경계를 새 머리 표면에 맞췄다.
- 작은 삼각형 귀와 짙은 눈, 홍채·동공 재질, 눈꺼풀 테두리를 새로 만들었다. 확대 검토에서 보인 각진 눈 구멍은 매끄러운 눈꺼풀 표면과 짧은 털로 보완했다.
- 코를 짙은 색으로 조정하고 혀가 아래로 내려오는 형태로 바꿨다.
- 머리·볼·가슴의 털 방향이 연속되도록 새로 배치했다. 눈 주변은 털이 눈 바깥으로 흐르게 하고, 코 표면의 털은 제외했다.
- 속털·겉털·주둥이·눈꺼풀·양쪽 귀의 Hair Curves를 분리했다. 총 272,597개 곡선이며 뿌리 UV와 표면 참조를 저장했다.

## 파일

- 편집 원본: `ArtSource/FaceRebuild/ogong_pomeranian_face_v10.blend`
- 털 없는 구조 확인용: `ArtSource/FaceRebuild/ogong_face_v10_structure.blend`
- 얼굴 정면: `ArtSource/FaceRebuild/v10_front.png`
- 사선: `ArtSource/FaceRebuild/v10_threequarter.png`
- 축소 표시: `ArtSource/FaceRebuild/v10_small.png`
- 부위별 곡선 수·길이 분포: `ArtSource/FaceRebuild/v10_manifest.json`

공식 Blender 5.2.2 LTS의 Python 모듈로 저장하고 Cycles / OpenImageDenoise로 렌더링한다. 사용자의 Windows Blender 화면을 직접 조작한 것은 아니다. 파일을 연 뒤 `F12`로 같은 구도의 렌더를 만들 수 있다. 원본 사진은 `Ogong_Photo_References` 컬렉션 안의 이미지 숨김을 해제하거나 이미지 편집기에서 확인한다.

저장된 파일을 Blender 5.2.2에서 다시 열어 8개 메시, 7개 Hair Curves 오브젝트, 272,597개 곡선, 표면·UV 참조와 내장 이미지 6장(텍스처 4장·사진 2장)을 확인했다. 곡선 좌표의 유효성과 양수 굵기도 확인했다. 검사 결과는 `v10_validation.json`에 기록했다.

## 남은 품질 작업

정면·사선 확대 렌더에서 짧아진 주둥이와 둥근 머리의 깊이를 확인했다. 코를 덮던 털과 각진 눈 경계를 보정했다. 사선에서는 털에 묻힌 작은 귀의 위치도 확인된다. 눈의 반사는 여전히 단순하고, 입꼬리의 어두운 경계와 균일한 볼 털은 실제 사진보다 인형처럼 보이는 부분이다. 현재 수정본을 사실적인 외형의 최종 품질로 판정하지 않는다.

보호자가 알아보는 오공이의 닮은 정도는 아직 확정되지 않았다. 사진과 비교해 볼의 볼륨, 눈꺼풀, 입꼬리, 털 뭉침과 비대칭을 더 다듬을 여지가 있다. 입 주변은 참고 메시의 세부 부분을 새 머리에 맞춘 구조이므로, 표정 애니메이션을 만들기 전에 연속된 표면과 변형 구조를 정리해야 한다.

털은 편집·렌더용 고밀도 곡선이다. Windows 데스크톱 앱에서의 실시간 성능은 아직 측정하지 않았다. 전신 연결, 몸통·다리·꼬리, 리깅과 앱용 털 변환은 후속 작업이다.
