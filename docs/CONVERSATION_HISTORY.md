# 대화 결정과 수정 이력

2026-10-06까지의 중요한 결정과 작업 변경을 정리한 기록이다. 감정 표현, 계정 정보, 대화 전문, 개인 사진은 복제하지 않았다. 최신 실행 상태와 재개 순서는 [HANDOFF.md](HANDOFF.md)를 따른다.

## 요구사항이 정해진 과정

1. 사용자가 우리 집 강아지 사진으로 3D 모델을 만들고 Windows 바탕화면에서 돌아다니는 펫을 요청했다. 원하는 동작은 **걷기·앉기·잠자기·클릭 반응**이다.
2. 전체 구조와 계획부터 차근차근 만들기로 했고, 사용자가 **바탕화면에서만** 활동하게 한다고 범위를 정했다. 항상 위에 떠 있는 펫으로 되돌리지 않는다.
3. 현재 컴퓨터에 Unity가 없어 **3D 작업부터** 진행하기로 했다. 일반 강아지보다 실제 오공이와의 닮은 정도와 세부 품질을 중요하게 요청했다.
4. 얼굴 정면, 전신 사선, 움직이는 정면, 측면, 야외 전신 등 사진과 사진 ZIP을 제공했다. 클라우드에는 원본 17장이 있었지만 이 자료는 Git에서 제외한다.
5. 사실적인 포메 모델의 털·메시 참고 화면을 제공했다. TurboSquid 상품 2491697은 Cinema 4D용 참고였고, Sketchfab 링크는 프린팅용 포메 모델 예시였다. 유료 다운로드 원본을 확보하지 않았으므로 해당 자산이 프로젝트에 있다고 가정하지 않는다.
6. 골든리트리버 ZIP과 별도 GLB를 제공했다. 큰 ZIP은 전송 제한으로 처리하지 못했고 별도 GLB는 검사했다. 701,574 삼각형 면, 단일 메시·재질, UV 1세트, 2K 이미지 4장이 있었으며 리그·애니메이션은 없었다.

## 전달·보관 결정

- 채팅 파일 링크가 여러 차례 열리지 않아 사용자가 Google Drive 전달을 요청했다.
- `fullbody04`, 이후 닫힌 입 `fullbody05`를 각각 사진 없는 전달용 ZIP으로 업로드했다. 최신 링크는 [자산 목록](artifacts/fullbody05.json)에 있다.
- 제작 소스, 계획, 작업 기록, 실제 3D 렌더는 GitHub `Desktop-Pet`에 게시했다. 모델 원본·개인 사진·외부 자산·중간 데이터는 기본적으로 Git에서 제외했다.
- 원본 사진이 들어 있는 제작 장면과 사진 없는 전달 장면은 다르다. 새 버전을 공유할 때도 같은 구분을 유지한다.

## Blender MCP와 로컬 재개 결정

- 사용자는 Windows Blender 5.2.2 LTS를 실행하고 MCP for Blender 1.8을 설치했다. 화면에는 `Connected on port 9876`이 표시됐고 `ogong_fullbody05.blend`가 열린 상태였다.
- Codex 설정 화면의 실행 명령은 Windows의 `mcp-for-blender.exe`였으며 `BLENDER_HOST=localhost`, `BLENDER_PORT=9876`을 사용했다. 이 주소·포트는 같은 PC의 Blender 서버 설정과 일치한다.
- 설정 화면만으로 서버 프로세스 실행이나 실제 MCP 호출 성공이 증명되지는 않는다. 이 클라우드 대화에서는 로컬 Blender MCP 도구가 제공되지 않았고 Windows 장면을 읽지 못했다.
- 사용자가 Codex를 재시작했지만 클라우드 실행 위치는 바뀌지 않았다. 대화의 실행 위치 변경 메뉴도 보이지 않는다고 알려 주었다.
- 최종적으로 **현재 작업과 대화의 핵심 내용을 GitHub에 보관하고, 같은 저장소를 Windows 로컬 Codex에서 열어 이어가기로 했다.** MCP를 다시 설치하거나 모델을 다시 생성하기 전에 로컬에서 실제 장면 읽기를 검증한다.

다음 대화에는 이 문서와 `HANDOFF.md`를 전달하면 된다. 다각도 그림이나 원본 사진은 여기 포함하지 않았으므로 로컬에 있는 실제 파일을 모델링 참조로 사용한다.
