# 얼굴·가슴 흰 털 시험

이 문서는 리트리버 얼굴을 유지했던 이전 시험의 기록이다. 사용자의 얼굴 수정 요청 이후 만든 최신 장면은 [포메라니안 얼굴 수정본](FACE_REBUILD.md)이다.

## 목적과 범위

오공이 사진에서 관찰한 털의 흐름을 Blender의 실제 곡선 털로 시험한다. 볼은 옆으로 퍼지는 털, 이마는 위와 바깥으로 흐르는 털, 주둥이는 짧은 털, 가슴은 아래로 떨어지는 긴 털로 나눴다. 각 부위에 속털과 겉털을 따로 둔다.

시험용 표면은 사용자가 제공한 리트리버 GLB의 머리·가슴을 복사한 것이다. 현재 얼굴의 비율과 귀는 리트리버 형태이며, 이 결과를 오공이의 외형 완성본으로 평가하지 않는다. 이번 단계의 판단 대상은 흰 털의 부드러움, 흐름, 밀도와 작은 화면에서의 표현이다.

원본 GLB와 사진은 변경하지 않았다. 곡선 생성은 이 작업 환경의 Blender 4.3.2에서 수행했다. 초기 렌더의 노이즈 문제를 해결하기 위해 공식 `bpy==5.2.2` 패키지를 별도 경로에 설치하고, Blender 5.2.2 LTS의 OpenImageDenoise를 사용하는 검토 장면을 준비했다. 사용자의 Windows Blender 화면은 직접 조작하지 않았다.

## 제작 방식

- 원래 표면의 삼각형 면적에 비례해 뿌리를 배치했다.
- 원본 UV와 색 정보를 사용해 눈·코·입의 털을 제한했다.
- 부위마다 방향장을 만들고 곡선을 굽혔다. 가슴은 중력 방향으로 추가 처짐을 줬다.
- 근처 털이 약하게 모이게 하고 길이·굵기·미세 굴곡에 제한적인 차이를 줬다.
- 속털과 겉털은 별도 Hair Curves 오브젝트다. 시험용 표면과 뿌리 UV 참조를 저장했다. 뼈대 변형을 따라가는 애니메이션 연결은 아직 구현하지 않았다.
- 전용 Hair BSDF를 사용하고 중립적인 조명에서 렌더링한다.

생성 스크립트는 `ArtSource/create_fur_study.py`, 최종 검토 렌더 스크립트는 `ArtSource/render_fur_study.py`다. 재실행하면 `ArtSource/FurStudy/`의 같은 이름 출력물을 덮어쓴다. 직접 수정한 Blender 파일은 다른 이름으로 저장한다.

약 29.6만 개의 곡선을 여덟 오브젝트로 나눴다. 곡선마다 제어점 12개를 사용했다. 실제 털 굵기는 사진만으로 측정할 수 없으므로, 검토 해상도에서 너무 가늘게 사라지는 속털과 겉털의 굵기를 조정했다. 정확한 수와 설정은 manifest에 기록했다.

중간 실험 `refine_fur_study.py`에서는 단순 확산·투과 재질도 비교했다. 현재 검토 장면 v03은 전용 Hair BSDF를 유지하며, 노출·털 굵기·노이즈 제거를 조정한 버전이다.

## 확인할 기준

1. 볼·이마·가슴의 흐름이 구분되는가.
2. 털 끝이 두꺼운 가시처럼 뭉치지 않는가.
3. 눈·코·입이 털에 가려지지 않는가.
4. 흰 털의 밝은 부분에도 털결과 부피가 남는가.
5. 256픽셀 렌더에서 외곽선과 얼굴의 주요 특징이 읽히는가.

작은 렌더는 표시 크기 검토용이다. Unity나 Windows에서의 실시간 성능을 측정한 결과는 아니다. 원본 곡선 털을 앱에 그대로 쓰는 방식은 아직 채택하지 않았다.

## 현재 확인 결과

- v03 정면 렌더에서 초기의 점 형태 노이즈가 줄었고, 볼 바깥과 가슴의 방향성 및 부드러운 외곽선이 보인다.
- 정면·45도·256픽셀 렌더를 모두 완료하고 확인했다. 256픽셀에서는 가는 털이 뭉쳐 보여, 앱용 제작에서 큰 털 덩어리와 외곽선의 조정이 필요하다. 이 축소 렌더도 실제 실행 성능을 검증한 결과는 아니다.
- 이마의 바깥 털은 아직 뻗치는 느낌이 강하다. 방향의 편차와 긴 잔털의 비중을 줄일 여지가 있다.
- 가슴 중앙에는 참고 모델의 조각된 표면이 남아, 일부 큰 털 덩어리가 거칠게 보인다. 실제 오공이용 표면에서는 털 아래 몸체를 정리한 뒤 그루밍한다.
- 얼굴·귀는 리트리버의 비율을 유지한다. 오공이의 닮은 정도를 검증한 결과가 아니다.
- 저장한 v03 `.blend`를 Blender 5.2.2 LTS에서 다시 열었다. 곡선 오브젝트 8개, 곡선 296,150개, 제어점 3,553,800개, 표면·UV 참조와 내장 이미지 4장을 확인했다.
