# 골든리트리버 GLB 검토

검토일: 2026-10-05 (한국 시간)

## 결론

제공받은 GLB를 Blender 4.3.2로 열고 정면·측면·45도·무채색 렌더를 확인했다. 서 있는 개의 체형과 발, 가슴·다리·꼬리의 털 흐름을 참고하는 데 유용하다. 기존 구형 도형 실험보다 얼굴과 몸의 해부학적 형태가 구체적이다.

오공이 제작에는 **몸체 구조와 털 표면의 참고 자료로 채택**한다. 이 자산을 그대로 애니메이션 기반으로 확정하지는 않는다. 얼굴·귀·꼬리·다리 비율을 크게 바꾸고 변형용 표면을 다시 구성해야 한다. 원본은 수정하지 않았다.

텍스처 슬롯의 존재가 재질의 물리적 정확성을 보장하지는 않는다. 새 모델의 재질은 새 조명과 배경에서 다시 검토한다. 실제 길이 단위는 파일만으로 확정하지 않았다.

### 표면 연결 검사

GLB의 UV 경계 때문에 나뉜 정점을 구분하기 위해, 위치를 소수점 여섯 자리로 반올림한 분석용 배열에서 연결성을 계산했다. 모델 파일 자체에는 병합을 적용하지 않았다.

- 위치 기준 정점 350,223개, 연결된 표면 1개.
- 이 분석에서 열린 경계 변과 3개 이상 삼각형이 공유하는 변은 발견하지 못했다.
- 면적이 정확히 0인 삼각형은 없었다.
- 이 검사는 자기 교차, 관절 변형, 눈·입의 애니메이션 적합성을 보장하지 않는다.

몸·얼굴·털을 독립적으로 조절할 부품이나 리그가 들어 있지 않다. 면 수가 많아도 눈꺼풀·입·관절 주변에 애니메이션용으로 배치된 면 흐름을 갖췄다고 볼 수 없다.

## 오공이와 비교한 수정 범위

| 부위 | 이 모델에서 본 형태 | 오공이 제작에 필요한 작업 |
| --- | --- | --- |
| 머리·주둥이 | 길게 나온 주둥이, 비교적 작은 머리 | 짧은 주둥이, 눈구멍·눈꺼풀, 둥근 머리와 볼 비율을 별도 설계 |
| 귀 | 양옆으로 늘어진 귀 | 머리 위의 작은 삼각형 귀를 만들고 털에 일부 묻히게 구성 |
| 몸통·다리 | 긴 몸통과 다리, 드러난 허리선 | 사진에 맞게 몸통·다리 비율을 바꾸고 가슴과 몸통의 털 부피를 따로 설계 |
| 꼬리 | 뒤로 길게 뻗어 올라가는 형태 | 등 위로 말린 꼬리와 풍성한 꼬리털을 새로 구성 |
| 털 | 표면에 붙은 털결과 갈라진 털 덩어리 | 이마·볼·가슴·옆구리·꼬리별로 길이와 방향이 다른 흰 털 제작 |
| 눈·입 | 표면에 통합된 눈과 열린 입·혀 | 눈알·눈꺼풀·입·혀를 표정에 필요한 구조로 분리하거나 재제작 |

큰 체형 변경은 기존 UV와 텍스처를 늘어뜨릴 수 있다. 수정한 형태의 UV와 재질은 별도로 정리한다. 털을 모두 조각 메시로 만들 경우 디테일 원본과 앱용 털 표현을 분리한다.

## 다음 제작 순서

1. 오공이 사진을 기준으로 머리·몸통·다리와 꼬리의 비율을 정한다. 이 리트리버는 서 있는 동물의 구조 참고로 사용한다.
2. 수정하기 쉬운 낮은 밀도의 표면을 구성한다. 관절·눈·입 주변에 필요한 면을 배치하고, 오공이의 얼굴·귀·꼬리를 만든다.
3. 정면·측면·45도에서 얼굴과 털 부피 가이드를 사진과 비교한다.
4. 기본 관절 변형을 확인한 후 부위별 털과 재질을 제작한다.
5. 디테일 원본과 앱용 자산을 나누고 걷기·앉기·잠자기·클릭 반응을 만든다.

이번 검토에서는 새 오공이 모델 제작이나 리깅을 진행하지 않았다. 원본 GLB에 라이선스 정보는 없었으며, 원본과 검사 파일은 Git 추적에서 제외한 로컬 참고 폴더에 보관했다.
