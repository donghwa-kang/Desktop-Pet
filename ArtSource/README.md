# Ogong 3D source

## Current: closed-mouth default

`FullbodyStudy/ogong_fullbody05.blend` makes a closed, neutral mouth the default expression. The chin and lower muzzle are rebuilt as a closed surface; subtle lip/philtrum details follow the surface, and the default scene contains no exposed tongue or tooth objects. The regional muzzle groom is adjusted around the lip contact. See [closed-mouth notes](../docs/CLOSED_MOUTH.md). This is a static sculpt, not a facial expression rig.

## Previous: full-body reference proportions

`FullbodyStudy/ogong_fullbody04.blend` extends the portrait into a standing quadruped using the user's five-view sheet as the primary proportional reference. It contains continuous head/neck/body/limb anatomy, a low curled tail, revised facial details, regional hair, hidden measurement landmarks and seven review cameras. See [full-body notes](../docs/FULLBODY_PROPORTIONS.md). The reference sheet was viewed in chat; exact pixel registration awaits its original file. This is a dense editable study without rigging or runtime optimization.

## Previous: portrait refinement

`PortraitStudy/ogong_portrait02.blend` refines the clean face against the original frontal photographs: smaller recessed eyes, eyelids, a taller nose with shaped nostrils, projecting muzzle pads and a revised central mouth opening. Nose pores, tongue color variation, iris fibres, separate muzzle fur, guard hairs, undercoat and sparse whiskers are editable. Three review cameras are bound to timeline frames 1–3. See [the portrait refinement notes](../docs/PORTRAIT_REFINEMENT.md).

The file remains a dense head/chest study with native Blender hair, not a rigged full-body or Unity asset. Original photographs are packed; the entire output directory is excluded from Git. Likeness still needs artistic review.

## Previous: clean continuous facial surfaces

The user rejected v10 for its uneven face and broken-looking mouth edges. The structural correction is `CleanFace/ogong_clean03.blend`, generated by `sculpt_clean_face.py`, `build_clean_face.py` and `groom_clean_face.py`. Its head, muzzle, mouth cavity, nose and tongue are newly built; none of the cropped retriever geometry or textures is retained. The head/nose surfaces are closed and symmetric, and the facial groom uses mirrored strand pairs. See [the correction record](../docs/CLEAN_FACE.md). This fixes the uneven connections; it does not establish photorealistic likeness.

## Rejected v10 face reconstruction

`FaceRebuild/ogong_pomeranian_face_v10.blend` rebuilds the head and collar as a continuous quad loft, replaces hanging ears with upright ear shells, adds dark eyes and smooth eyelid surfaces, and shortens the supplied nose/mouth detail. Its native Hair Curves use a continuous direction field, with separate muzzle, eyelid and ear grooming. Two original photos are packed in a hidden reference collection. This is an editable head/chest revision, not a finished full-body character or an animation-ready asset.

`rebuild_pomeranian_face.py` generates the structure; `groom_pomeranian_face.py` adds the groom and renders it. Both run with Blender 5.2.2's Python API. The default output tag is `v10`; rerunning overwrites that revision, so save manual work under another filename. Generation depends on the local v03 fur study and original photos. The resulting `.blend` has its textures and two references packed. See [face reconstruction notes](../docs/FACE_REBUILD.md).

## Status: rejected modeling experiments

`ogong_blockout_v01.blend` and `ogong_blockout_v02.blend` were built in Blender 4.3.2 using primitive forms and procedural fur. The user rejected their appearance. Neither is an accepted sculpting base: the face structure, silhouette and coat do not meet the requested likeness and detail. Both have no rig or production animation. Preserve them as experiments rather than continuing this construction method.

The v02 file was reopened in Blender 4.3.2. Opening either file in the user's reported Blender 5.2.2 environment has not been verified here. This cloud workspace cannot control the user's Windows Blender session.

The scripts `create_ogong_blockout.py` and `refine_ogong_v02.py` regenerate their respective experimental files and images in `Previews/`; running them overwrites those outputs. Preserve any manual edits under a new name.

Reference photos unpacked from the user's ZIP are in `../ReferencePhotos/`, excluded from Git. Four representative images are also packed into the `.blend` so the file opens with its main visual references on the user's Windows computer. For that reason the `.blend` file is also excluded from Git until the user decides where to store it.

Preview angles for each version: `front`, `side`, `threequarter`, and `face` in `../Previews/`.

## Retriever reference inspected

The large ZIP could not be transferred, but the subsequently supplied `Meshy_AI_Golden_Retriever_in_P_0707032631_texture.glb` was received and inspected successfully. It has 701,574 triangles, one mesh/material, one UV set and four embedded 2K images. No armature, skin weights, animation or shape keys are included. After reconnecting coincident export positions for analysis, it forms one connected surface.

`inspect_retriever.py` imports the GLB without changing the source mesh/materials, records its Blender structure, adds an inspection studio and renders front, side, three-quarter and clay views. Run with Blender and the input/output paths as documented in its header. It overwrites inspection outputs in the selected output directory.

The original copy, renders and inspection scene are stored in `../ReferenceAssets/retriever/`, excluded from Git. Read [the asset review](../docs/RETRIEVER_ASSET_REVIEW.md) for measured findings and limitations.

Next: use its standing anatomy and sculpted coat as references while constructing a lower-density surface with suitable joint and facial topology. Ogong's shorter muzzle, small upright ears, proportions and curled tail require substantial new work. Review likeness before final grooming, then retain separate detailed and runtime assets. No new Ogong model or rig was made during this inspection.

The linked Cinema 4D product is a visual reference and an unpurchased candidate; its fur transfer and rig are unverified. See [the revised asset plan](../docs/3D_ASSET_PLAN.md) for verified product information, sources and review gates.

## Previous face and chest fur study

Following the user's approval, `create_fur_study.py` builds a directional white-fur test on a copy of the reference retriever's cropped head/chest. The anatomical proportions remain those of the retriever. Eight native Hair Curves objects separate forehead, cheek, muzzle and chest undercoat/outercoat. This is a material/grooming study, not the finished Ogong face or a runtime asset.

`render_fur_study.py` uses the official Blender 5.2.2 Python module with native OIDN denoising to prepare the v03 review scene. Local generated outputs are in the Git-ignored `FurStudy/` directory. `refine_fur_study.py` records an intermediate shader comparison. See [the fur study notes](../docs/FUR_STUDY.md) for scope and review criteria.
